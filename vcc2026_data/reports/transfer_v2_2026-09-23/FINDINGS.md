## 2. 구현 (코드: `scripts/tv2_*.py`)

- **`tv2_sources.py`:** 소스별 원시 합계에서 **진짜 fold change**(CPM pseudocount c)를 계산하고, 소스별 전체 스크린
  평균(중심화 벡터)을 함께 저장한다. 공식 타깃이 0개인 소스(RPE1/HepG2/Jurkat/K562-essential)는 뺐다.
- **`tv2_model.py`:** 가족 가중 융합(K562 / HCT116 / HEK293T / CD4 / KOLF / FENG / H1), 소스 중심화,
  소스 간 일치도 수축, **promoter-neighbour prior**(GENCODE v47 TSS ≤5kb, ≤500bp에서 15%, 로그 램프),
  on-target knockdown. `split()`은 promoter와 knockdown을 **항상 곱셈 override**로 분리한다.
- **`tv2_emit.py`:** 생성 모드 네 가지.
  - `iid_mult`: 타깃별 독립 추출 × FC.
  - `shared_mult`: 공유 블록 × FC.
  - `shared_cellshift`: 기존 S1–S4 방식.
  - **`shared_cellshift_gated`**: 5 CPM 미만 유전자는 곱셈으로, 미발현 유전자에 카운트를 만들지 않는다.
- **`tv2_submit_build.py` / `tv2_submit_chain.sh` / `tv2_upload.sh`:** 스트리밍 빌드 → `vcc prep` → 업로드 → 영수증.

### 배운 것
1. **게이트 cellshift는 공짜 이득이다.** 미발현(<5 CPM) 유전자의 가짜 카운트는 DE 채점에 들어가지 않고 PDS만 해쳤다.
   효과는 H1 PDS +0.015, 공식 PDS +0.010. MSE는 14.7 → 8.3.
2. **promoter prior는 반드시 곱셈으로 적용해야 한다.** log1p 셀 이동 공간에 넣으면 이웃 유전자가 0이 되어
   log2FC가 발산한다(NMAE 0.922 → 0.998). 곱셈으로 넣으면 +0.0015.
3. **새 융합(fold change, K562 중심, 중심화)은 PDS를 크게 올린다**(H1 0.777 → 0.865, 대리 6개 평균 0.61 → 0.72).
   **하지만 DE 지표(reach/fid/NMAE)는 동일가중·무중심 평균 + 셀 이동 변환이 더 좋다.**
   - K562 가중을 높이면 PDS는 오르고 reach와 NMAE는 떨어진다.
   - 셀 이동 변환 자체가 5–50 CPM 유전자의 변화를 증폭해 방향이 맞는 DE 판정을 만든다
     (곱셈으로 바꾸면 reach 0.276 → 0.200).
   - 결과적으로 PDS 이득과 DE 손실이 상쇄되어 composite가 같거나 낮아진다.
4. **타깃별 독립 추출은 작은 진폭에서 PDS를 망친다.** 샘플링 잡음(~16)이 예측 신호를 덮는다.
   공유 블록은 잡음이 공통이라 PDS 손실이 작다(+0.01).
5. **정직한 단일 생성으로는 MSE 점수를 받을 수 없다.** 1 + ρ − 2c√ρ < 1에는 c ≳ 0.5가 필요한데, 우리 c는 ~0.25다.

## 4. 왜 0.17–0.20에 못 갔나 (그리고 다음 레버)

다음 슬롯에서 가장 먼저 시도할 것(공식 증거 기반): S6에서 새 융합 비중을 올린 변형(0.75/0.25, 새 융합 α 1.6–2.0)과
A 컨텍스트에서 CD4 가중 상향. S5→S6에서 새 융합 50%가 NMAE/reach로 +0.0077을 줬으므로 비중 곡선을 공식으로 확인할 가치가 있다
(H1은 이 방향을 과소평가했다).


- **H1 composite 최고(0.200)는 기존 방식 대비 +0.006에 그쳤고, 공식도 +0.0065였다.**
  새 융합의 PDS 이득(공식 추정 +0.04–0.08 raw)은 같은 셀로 채점되는 DE 지표 손실과 상쇄된다.
  수도벌크(PDS/MSE)와 셀 분포(DE)를 같은 한 번의 생성으로 맞춰야 하기 때문이다.
- **상위권의 해법은 둘을 분리하는 방출 엔지니어링이다.** 공개 AtlasShift의 dual-moment 렌더러,
  그룹 합 고정(repair_bulk_totals), depth별 배분이 그것이다.
  - 그룹 합 고정은 채점기의 #348 잡음 보정 "rebate"를 수확한다. 주최측이 문서화한 잔여 허점이다.
  - depth 의존 배분은 생물학적 근거가 없는 지표 맞춤이다.
  - 둘 다 이번에는 **의도적으로 구현하지 않았다**(gap 분석 §7 권고). 진행하려면 사용자 결정과 주최측 확인이 필요하다.
- **그 밖의 레버:** 계열이 맞는 데이터(Jurkat CRISPRi GSE249595, VIPerturb-seq Flex K562)는 확보하지 않았다.
